# Suivi Coaching

Petite web app pour suivre les séances de coaching : packs d'élèves (5, 8, 10, 20 séances), clients facturés en fin de mois, alertes de fin de pack et de fin de mois, séances du jour depuis Google Agenda.

Un seul fichier : `index.html`. Les données sont stockées dans le navigateur (localStorage).
